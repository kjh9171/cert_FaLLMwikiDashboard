시스템 아키텍처 개요
1. Client Layer
Next.js / PWA Dashboard
거실 월패드 (Kiosk Mode)
영수증 카메라 OCR 업로드
WebSockets Realtime Sync
2. Core & RAG Service Layer
FastAPI & LangChain Agent
PaddleOCR / EasyOCR Engine
Function Calling Agent
Redis Pub/Sub Message Broker
3. Data & Storage Layer
PostgreSQL 16 Engine
pgvector (HNSW Index 1536d)
Finance / Receipt / Todo Schema
ACID + Hybrid Vector Search
데이터베이스 스키마 주요 테이블
테이블 주요 컬럼 설명
users user_id (VARCHAR PK), name, role, color_code, avatar_initial, birth_date 가족 구성원 정보 및 태그 색상
finance_transactions transaction_id (PK), user_id (FK), category_code, type, amount, transaction_date, payment_method 가계 수입 및 지출 통합 원장 테이블
calendar_events event_id (PK), user_id (FK), title, start_time, end_time, category, color_tag 월간/일간 일정 데이터 관리
todos todo_id (PK), user_id (FK), title, is_completed, completed_at 가족 구성원별 할일 목록
receipts receipt_id (PK), store_name, total_amount, image_url, ocr_confidence, scan_status OCR로 스캔된 영수증 정보
wiki_document_chunks chunk_id (PK), doc_id (FK), chunk_text, embedding (vector(1536)) pgvector HNSW 벡터 코사인 유사도 인덱스
포트 구성 (Docker Compose)
