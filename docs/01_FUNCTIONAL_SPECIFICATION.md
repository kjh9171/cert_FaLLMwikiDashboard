# 📋 가족 LLM WIKI & 가계/영수증 통합 시스템 기능 정의서 (Functional Specification)

- **프로젝트 명**: 가족 지식 비서 및 스마트 가계/영수증 관리 대시보드 (Family LLM WIKI & Household Finance Platform)
- **버전**: v1.3.0
- **작성일자**: 2026년 11월 5일
- **대상 사용자**: 가족 구성원 (지훈, 민서, 하늘, 바다) 및 시스템 관리자

---

## 1. 시스템 개요 및 목적

본 시스템은 가족 구성원의 일상생활 관리(일정, 할 일, 육아 성장 기록), 가계 재정 관리(수입/지출 분석, 예산 관리, 영수증 OCR 자동 인식), 그리고 온디바이스/로컬 중심의 **RAG(Retrieval-Augmented Generation) 기반 LLM 지식 비서**를 결합한 통합 홈 인텔리전스 플랫폼이다.

### 1.1 핵심 가치
1. **Single Source of Truth**: 흩어져 있는 가족 일정, 영수증, 육아 매뉴얼, 가전 가이드 등을 하나의 홈 대시보드로 일원화.
2. **Automated Expense Tracking**: 종이/전자 영수증을 업로드하면 OCR 엔진이 상호명, 품목, 금액을 자동 파싱하여 가계부 원장에 직결.
3. **Local-First Family AI Assistant**: 가족 전용 위키 문서(Markdown) 및 가계부 데이터를 pgvector 기반으로 임베딩하여, 민감한 가족 정보를 안전하게 로컬 환경에서 검색 및 에이전트 자동 제어.
4. **Kid-Friendly & Growth Oriented**: 자녀(하늘, 바다)의 생애주기별 성장 데이터(신장, 체중, 백신 접종, D-day)를 추적하고 시각화.

## 2. 사용자 역할 및 권한 체계 (Role-Based Access Control)

| 역할 (Role) | 대상 | 권한 및 기능 범위 |
| :--- | :--- | :--- |
| **Admin (가족 관리자)** | 지훈, 민서 (부모) | 전체 시스템 설정, WIKI 문서 CRUD, 가계부 원장 전체 수정/삭제, 예산 설정, 사용자 관리, API 키 관리 |
| **Member (가족 구성원)** | 지훈, 민서 | 본인 할 일/캘린더 관리, 영수증 업로드, 지출 등록, LLM 채팅 질의, 여행 체크리스트 체크 |
| **Child (어린이 구성원)** | 하늘 (6세), 바다 (3세) | 본인 성장 카드 확인, 미디어 플레이어 사용, 어린이 친화형 캘린더 열람 |
| **System Agent (LLM Engine)** | Ollama / Llama3 | RAG 검색, 가계 데이터 질의응답, 캘린더 등록/할 일 추가 Function Calling 실행 |

      │ 
      ├─ (2) 자연어 질문 ("이번달 지출?") ─► [LangChain / Ollama Agent]

      │                                             ├─► [PostgreSQL Finance/Calendar SQL 질의]
      │                                             └─► [최종 종합 자연어 응답 생성]
      │ 
      └─ (3) 위키 문서 신규 등록 ────────► [Text Splitter / Embedding Model] ──► [pgvector HNSW 인덱스 적재]
